# Оригинальные материалы лабораторной №3

Все PNG созданы специально для этого проекта процедурным генератором
[`scripts/generate_textures.py`](../../scripts/generate_textures.py).
Сторонние изображения, фотографии, текстуры, шрифты и готовые наборы материалов
не использовались. Эти оригинальные активы распространяются на условиях
корневого файла [`LICENSE`](../../LICENSE), как и остальной проект.

В репозитории находятся **10 настоящих RGB PNG размером 512×512**:

| Пресет | Albedo | Specular | Emissive |
|---|---|---|---|
| `cosmic_core` | ✓ | ✓ | ✓ |
| `nebula_mist` | ✓ | ✓ | ✓ |
| `holographic_prism` | ✓ | ✓ | ✓ |
| `prism_grid` | ✓ | отсутствует намеренно | отсутствует намеренно |

Имя файла: `<preset>_<type>.png`, например `cosmic_core_emissive.png`.
Приложение загружает эти файлы с диска; Python во время работы не требуется.
`prism_grid` проверяет поддержку отсутствующих дополнительных карт: приложение
подставляет чёрные Specular и Emissive, поэтому материал остаётся матовым и
не имеет собственного свечения.

**Cosmic Core.** Многомасштабная туманность синего и фиолетового цветов,
плотная звёздная пыль, редкие выразительные звёзды и ветвящиеся энергетические
прожилки. Основа остаётся тёмной; эмиссия локализована на циановых/фиолетовых
прожилках, отдельных звёздах и узлах туманности. Карта бликов усиливает
отдельные облака и прожилки, сохраняя менее блестящие области.

**Nebula Mist.** Более светлая сине-фиолетовая туманность с другим фиксированным
случайным зерном, более густыми облаками, мелкими звёздами и умеренной эмиссией.

**Holographic Prism.** Насыщенная иридесцентная палитра, тонкие диагональные
интерференционные полосы, треугольные участки, геометрическая сетка и редкие
цифровые дорожки с контактами. Карта Specular согласована с крупными цветовыми
полосами и гранями рисунка; небольшие неоновые дорожки формируют более слабую
эмиссию, чем Cosmic Core. Динамические UV и смешивание выборок реализуются
шейдером приложения, а не встроены в PNG.

**Prism Grid.** Более тёмная вариация голографической текстуры с подчёркнутой
сеткой. Цветные линии нарисованы в Albedo и освещаются внешними источниками.

В генераторе используются периодический многомасштабный шум на основе FFT,
аналитические волны и маски, ломаные линии, растеризация Pillow и Gaussian blur.
Карты одного пресета используют общие поля и маски, поэтому детали Albedo,
Specular и Emissive совпадают. Базовый seed — `31010`; независимые потоки для
каждого пресета позволяют воспроизводить изображения. Текстуры предназначены
для локальной развёртки одной пятиугольной грани; бесшовность всех нарисованных
звёзд и цифровых дорожек на границах изображения не заявляется.

Для повторной генерации нужны Python 3.10+, NumPy и Pillow:

```powershell
python -m pip install numpy pillow
python scripts/generate_textures.py
```

При желании можно сохранить обзор всех карт:

```powershell
python scripts/generate_textures.py --contact-sheet .tools/texture-contact-sheet.png
```

Генератор не добавляет цветовой профиль или gamma-метаданные. Albedo и Emissive
описывают цвет и загружаются приложением как sRGB; Specular содержит линейные
коэффициенты в серых оттенках и загружается как UNORM. Эмиссия рисует цвет самой
поверхности; Bloom и свечение за пределами силуэта не требуются.

Проверка PNG и визуальных свойств не требует NumPy/Pillow:

```powershell
python tests/verify_texture_assets.py
```

Тест проверяет сигнатуру, CRC, декодирование PNG, размеры, различие пресетов,
диапазон яркостей, насыщенность, контраст Specular, локальность Emissive и
намеренное отсутствие дополнительных карт `prism_grid`.
